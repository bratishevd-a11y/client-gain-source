# Client Surge

1. Общая концепция

Тип сайта: корпоративный Landing Page (с возможностью дальнейшего масштабирования до многостраничного сайта).

Основная задача сайта — максимально конвертировать посетителей в заявки.

18. Анимации

Использовать GSAP или Framer Motion.

Эффекты:

 плавное появление секций;

 fade-up;

 scale;

 slide-left;

 slide-right;

 анимация счетчиков;

 hover-анимации;

 параллакс на первом экране;

 плавный скролл по якорям.

Продолжительность анимаций — 0.4–0.8 сек.

22. Общие требования к Front-End

 Семантическая HTML-разметка.

 Pixel Perfect по макету (допуск не более 2–3 px).

 Полностью адаптивная верстка.

 Кроссбраузерность.

 Все интерактивные элементы имеют состояния hover, active, focus и disabled.

 Поддержка клавиатурной навигации и базовых требований доступности (ARIA).

 Использование CSS Grid и Flexbox.

 Чистый, модульный код с повторно используемыми компонентами.

 Оптимизированные шрифты (preload, font-display: swap).

 Плавная работа анимаций без просадок FPS.

 Все формы подключены к CRM/API с валидацией и обработкой ошибок.

 SEO-ready: корректная структура заголовков H1–H3, Open Graph, favicon, микроразметка Organization и LocalBusiness (при необходимости).

Ожидаемый результат

В результате должна быть реализована современная премиальная посадочная страница уровня ведущих digital-агентств (например, Clay, Ramotion, Halo Lab, Locomotive), которая вызывает доверие с первых секунд, демонстрирует экспертность компании и максимально эффективно конвертирует посетителей в заявки на услуги лидогенерации.
